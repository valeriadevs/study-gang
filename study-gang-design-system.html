Day 03. Recursion.
Sub-displaySpectral · 500 · italic
A function that calls itself — until it doesn't.
BodyInter · 400 / 500 / 600
Recursion is one of those ideas that feels circular until suddenly it doesn't. A recursive function solves a problem by calling a smaller version of itself — over and over — until it hits a stopping condition. That stopping condition is called the base case.

public static int fact(int n) {

    return n * fact(n - 1);     // recursive call
}

07

Rules.

Color
· one accent (mint) used at most twice per screen
· warn reserved for stack-overflow / destructive only
· never overlay two saturated colors
· never use cream (ac2) as primary text
Typography
· display = Instrument Serif; never pair with another serif
· italic sub-display only on h3 / sub-lines
· body ≥ 13px on dense UI; ≥ 15px on reading surfaces
· mono = code + meta + numerics only
Surfaces
· bg = canvas, sf = panel, sf2 = raised inside panels
· hairline borders over shadows (always 1px oklch bd)
· radius scale: sm → md → lg → xl · never in-between
· spacing on 4px grid; default stack = 16px
Motion
· 120ms hover, 240ms entrance, 2-3s loops
· respect prefers-reduced-motion
· one motion at a time per zone · no cascading loops
· hue shifts allowed only via color-mix on tokens
